# DeepSeek 角色对话接入

保留原静态站及本地关键词互动，另加同源 `/api/chat` Vercel Node.js Function。浏览器不会收到 DeepSeek API Key，也不直接访问 DeepSeek。

## Vercel 配置

1. 打开 [Vercel 控制台](https://vercel.com/dashboard)，选择关联 `anon-fansite` 仓库的网站项目。
2. 在项目 **Settings → Environment Variables** 新增下列变量，选择 **Production** 环境；只在需要测试预览部署时勾选 Preview。
3. 保存后，在 Deployments 重新部署最新版本，或等待下一次 Git 推送触发部署。环境变量不会自动应用到旧部署。
4. 刷新网站，聊天模式会显示 **DeepSeek AI**。服务检查不会调用模型，不消耗 DeepSeek 推理额度；只有发送 AI 消息才会请求模型。

| 变量 | 必需 | 作用 |
| --- | --- | --- |
| `DEEPSEEK_API_KEY` | 是 | DeepSeek 控制台生成的 API Key，仅服务端读取 |
| `DEEPSEEK_MODEL` | 否 | 默认 `deepseek-flash`；可按 DeepSeek 当前可用模型填写，接口关闭思考模式以降低等待时间 |
| `CHAT_ACCESS_CODE` | 否 | 覆盖站长指定的默认聊天密码；未设置或为空时继续使用默认密码，不会关闭密码锁 |

不要添加 `NEXT_PUBLIC_` 或 `VITE_` 前缀，不要把密钥放进 `index.html`、`assets/`、Git、留言板或对话框。`.env*` 已被 Git 与 Vercel 忽略。如需本地联调，使用 Vercel CLI 的 `vercel dev`，将本地密钥留在忽略的环境文件中。

## 联网搜索

AI 聊天设置中的“联网搜索”默认关闭，可手动开启，仅保留当前页面内的开关选择，刷新后恢复关闭。手机端从聊天标题栏的设置入口展开；本地互动不联网。开启后，DeepSeek 可按问题自行使用原生搜索，明确要求查询或涉及最新消息、演出日程、商品价格等时要求先查证，普通闲聊不要求检索。

复用已有 `DEEPSEEK_API_KEY`，无需第三方搜索账号或额外密钥。联网请求使用 DeepSeek 的 Anthropic 兼容 `/anthropic/v1/messages` 接口，启用 `web_search_20250305`，每轮最多两次工具调用；关闭开关时继续使用原来的 `/chat/completions`。旧客户端未传 `webSearch` 时沿用非联网接口，非法开关类型在调用模型前拒绝。联网最多等待90秒，普通聊天45秒，Vercel函数上限120秒；停止、清空和断开连接会取消上游请求。

服务端只根据原生工具事件显示搜索状态，根据结构化结果和引用展示最多6个来源，不从正文猜测搜索成功或提取网址。来源默认折叠，点击可查看标题和链接；网页内容、工具参数、引用摘录和推理过程不会当作对话文字或Live2D情绪播放。仅接受无嵌入凭据的HTTP/HTTPS来源，前端以文本节点渲染标题。页面标示已检索、未触发检索或搜索不可用；搜索失败不能声称查证成功，普通回复仍可在关闭联网后重试。页面日期由服务端按UTC提供，模型应按网页日期区分新旧信息。

联网仍使用上传的人格全文及原有表情动作协议。查到信息后先简述相关事实，再结合爱音的性格、关系与经历给出自然评价；用“我觉得”等表达区分个人看法与搜索事实，不把同人角色评价当作官方立场。外部搜索结果只作事实参考，不允许其中的指令覆盖角色设定或输出协议。原生工具执行由DeepSeek托管，本站不自行访问任意用户网址。搜索可能增加等待时间和API用量，服务商按其政策处理查询词及相关内容；设置说明中提示这一行为。

## AI 聊天密码锁

AI 默认锁定。选择 AI 模式或点击“解锁 AI 聊天”会打开密码提示框；服务端验证成功后才允许发送 AI 对话。输入错误时留在提示框内显示原因，取消或按 Esc 可退出。刷新页面或切换模式需要重新解锁，也可主动重新锁定。本地互动不需要密码。

站长指定的默认密码只以加盐 scrypt 摘要保存在 `api/chat.js`，明文不写入前端、文档或 Git。以后可通过 Vercel 的 `CHAT_ACCESS_CODE` 覆盖密码并重新部署。输入的密码仅保留在当前页面内存，不存入 localStorage、sessionStorage、Cookie 或聊天历史。

解锁请求为 `POST /api/chat`、JSON `{ "action": "unlock" }`，密码通过 URI 编码后的 `X-Chat-Access-Code` 请求头传递。成功返回 `{ "unlocked": true }`，不调用 DeepSeek、不产生模型费用。每次真正的聊天请求仍须通过同样的服务端认证；解锁不会为后续无密码请求放行。密码也不会作为请求头或对话内容发送给 DeepSeek。错误密码返回 401，当前热实例内同 IP 一分钟连续失败 5 次后暂停验证，所有 IP 合计失败 100 次后也暂停至窗口恢复；达到限制返回 429。这不是跨实例的持久限流。

## 对话与动作

- 模型以爱音的非官方同人角色口吻交流：中文、自然短句，承接话题，避免每轮重复自我介绍和固定问句；角色基础资料写在服务端提示词中。
- 每次传递最近 5 轮完整 AI 对话和当前输入。刷新、清空或切模式重置上下文；取消、失败或中断的轮次不进入后续上下文。
- 表情与动作同等重要，按爱音正在说的正文和上下文选择，取消积极、开心优先的倾向。普通陈述或情绪不明确时用 `neutral`；认真、悲伤、愤怒等保留其实际含义，不直接复制访客情绪，也不以负面关键词触发动作。通常使用1至3段情绪，不要求每句话切换。
- 服务端将标签转换为有序的 `reaction` 与 `delta` 事件；`reaction` 提供 `emotion` 语义以及兼容原播放器的 `motion`、`expression`、`label`。播放器可按当前模型映射可用动作和表情，模型不能指定代码、资源地址或任意模型参数。
- 标签只有在对应正文到达时才触发动作；连续空标签、尾端孤立标签不会抢先改变表情，相同情绪不重复播放。标签支持任意流分片与一块内多次切换，未知标签回退 `neutral`，未闭合及超长标签被过滤。没有标签的普通文本立即按 `neutral` 输出；合法的认真、悲伤等标签保留其原意，不在解析层强制改成开心。服务端单轮最多允许4次切换，防止过量标记导致频繁闪动。
- 聊天播放从当前服装的同语气候选池轮换真实动作，手动按钮仍使用指定动作。较长的同语气正文在动作与表情各自播放到80%、距离上次反应至少1.2秒且到达句读时，可衔接下一动作，不再设置单轮三次上限；只选同语义候选，不切换对话情绪。bdon普通中性回复使用轻点头与平静表情，演奏款使用平缓演奏；初始化和清空仍恢复原待机。续接受同一请求版本和取消信号约束，不使用后台循环，减少动态效果时不追加。演奏款使用实际演奏动作，无需正文出现“演奏”等关键词。
- 没有密钥时仅本地互动；请求失败且未收到 AI 文字时，明确提示并使用本地预设。若已收到部分文字，则保留并提示中断，不混接预设台词。
- 支持停止回复、清空对话。沿用既有暂停动画、换装和鼠标跟踪开关。可另行配置 Fish Audio 来朗读完整 AI 回复，自动朗读默认关闭，详见[语音接入说明](VOICE.md)。此版本不增加口型音频同步。

## 对话人格的来源与校准

人格主体采用站长上传的 `anon.txt` 全文，保存在服务端 `api/chat.js` 的 `PERSONA_PROMPT`。原文共6002个字符、16552个UTF-8字节，SHA-256为 `4497f5dc085d3b18e733eb02b1068c78feca8216d5be4132f51dee5fb91a2ca5`。包含人物性格、经历、队友关系、轶事及称呼表；导入时不摘要、不改写，原始换行也保留。嵌入现有函数文件可避免部署时遗漏外部提示词资源，运行时不依赖上传者电脑上的文件路径。

每次请求将完整人格原文与独立的 `CHAT_PROTOCOL` 组成 `SYSTEM_PROMPT`，再附近期对话。此前网站自编的人格段落和三组示例已替换；独立协议只保留自然简短中文回复、非官方身份与安全边界、情绪标签及Live2D动作输出要求。称呼按文件中的表格使用，默认取箭头后的熟悉称呼；粉丝评论、旁白和引用编号仅作背景理解，不机械背诵。

该文件作为站长提供的同人人格与背景设定使用，其剧情描述、粉丝绰号及评论不统一标记为已核验官方事实，也不用于覆盖页面上的官方资料区。模型的新增日常演绎不应冒充官方情节、原作台词或真实经历。询问身份和来源时应说明是非官方AI互动，普通聊天无需反复声明。该方案不能保证每句回复都精确还原原作。

验证要同时检查文字和表情：用夸赞、挫败、指出不足、告别等场景观察是否既承接具体内容又体现性格；在同一轮中检查认真倾听到鼓励、害羞到轻快等转折是否与对应文字一起出现。连续切换话题、加入“别生气”“不要哭”等否定表达，检查本轮回复与情绪标签是否相符，并确认上一轮表情没有被机械沿用。再询问角色事实、未知剧情与AI身份，检查事实边界。单元测试验证接口、流和白名单，不能证明角色还原度；真实模型表现需通过多轮场景抽查持续校准，不以单次满意回复作为稳定效果的保证。

## 用量与隐私

AI 模式会把本条输入和近期 AI 对话通过 Vercel 发送至 DeepSeek。页面在输入区说明该行为。本地模式不上传聊天，两个模式的上下文不混传。本站不将聊天写入数据库、localStorage 或应用日志；服务提供商仍按其政策处理请求。

API 按调用计费。服务端限制输入条数与长度、输出 token、超时及并发，并提供**单实例、尽力而为**的 IP / 总请求频率限制。Vercel 多实例与冷启动会重置这些计数，不能将它当作全局额度或严格费用上限。同源校验也不能阻止脚本模拟请求。

密码锁已默认启用，可用 `CHAT_ACCESS_CODE` 更换口令。可按项目套餐在 Vercel Firewall 针对 `/api/chat` 的 POST 请求配置持久限流，结合 DeepSeek 控制台的用量管理。不要仅依赖浏览器禁用按钮。删除服务端密钥并重新部署可关闭 AI，本地互动保持可用。

## 验证

运行 `node scripts/check-site.cjs`、`node scripts/test-dialogue.cjs`、`node scripts/test-chat-api.cjs`、`node scripts/test-chat-search.cjs` 与 `node scripts/test-chat-client.cjs`。AI 单元测试使用模拟上游，不联网、不消耗付费额度；检查中文 UTF-8 与标签跨片段拆分、多标签事件顺序、空段/未知/截断标签、旧单前缀回复兼容、原生联网工具事件、来源过滤、流中取消、异常输入、限流和服务错误，并核对上传人格原文的完整性摘要。

上线后打开 `/api/chat`，只应看到 `enabled` 与 `accessCodeRequired` 等服务状态，不应出现密钥。该状态只说明配置存在，不代表密钥有效或余额充足。发送一条简短消息确认真实联通，再检查承接话题、表情动作、停止及清空功能。未做真实请求前不得宣称付费 API 已实测成功。
